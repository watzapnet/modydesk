# ModyDesk

ModyDesk is a peer-to-peer remote desktop application for Windows.

## Download

Get the latest binary from the [Releases page](https://github.com/watzapnet/modydesk/releases/latest):

1. Download `modydesk.exe` from the latest release.
2. Run it. No installer, no admin rights required.
3. Share your 9-digit ID with the other side, or paste theirs to connect.

The application checks this repository for new releases on launch and every 30 minutes afterwards. When a new version is published, the running app prompts you to update before continuing.
